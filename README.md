# Sistema-Gestao-Doacao-Sangue
O Sistema de Gestão de Doação de Sangue é um projecto académico desenvolvido no âmbito da Licenciatura em Docência de Programação Informática do Instituto Superior Dom Bosco (ISDB). O sistema tem como objectivo apoiar a gestão de dadores, hospitais, campanhas de doação, pedidos de sangue, doações e notificações.

Objectivos:
Gerir utilizadores e dadores.
Gerir hospitais participantes.
Registar doações de sangue.
Gerir campanhas de doação.
Criar e acompanhar pedidos de sangue.
Enviar notificações aos utilizadores.
Gerir tipos sanguíneos.

Tecnologias:
Microsoft SQL Server;
SQL Server Management Studio (SSMS);
MySQL Workbench (apenas para modelação EER);
PlantUML / PlantText;
Git e GitHub.

Estrutura do Projeto:
database/ – Scripts SQL Server;
diagrams/ – Diagramas UML e DER;
docs/ – Relatório académico;
assets/ – Imagens utilizadas no relatório.
